# Wayfarer — Premium Journey Research Integration

**Status (13 October 2026): Local preview candidate; NOT deployed to Vercel.**

This is an incremental upgrade to the recovered, premium-design `wayfarer-journey-ai` application, preserving its cinematic design and original working flows (Discover, Journey Studio, Arrival Companion, saved journeys) while introducing a protected travel-search research workspace.

## What's new

- `travel-research.js`: Progressive-enhancement UI added **inside Journey Studio**. Users enter departure/arrival three-letter IATA codes, their own group airfare allowance, and a **separate private beta access code**. The existing country index, worldwide destination search, nearby airports/hotels, Groq itinerary flow and Arrival Companion are unchanged.
- `api/travel-search.js`: a server-only SerpApi adapter for Google Flights / Hotels searches. The browser never receives the SerpApi key. Queries occur **only after an explicit user click** and valid beta access code, never as global daily scraping.
- Search prices are tagged by source and timestamp, not described as confirmed tickets or room availability. An adult airline search price multiplied by group size is labeled **indicative**, NOT a final repriced round trip. Only hotels with an explicit total search rate are displayed.
- Unconnected restaurant menu pricing and local transit fares are presented as unavailable, not generated by AI.
- The retired Amadeus pricing button is repurposed as navigation to the new protected Travel Research section; no dead Amadeus call is made.
- Light per-instance abuse throttling is a non-durable safeguard, NOT a global quota protection system.

## Vercel Preview configuration — premium project only

**Project:** `wayfarer-journey-ai`, not `wayfarer-world-travel`.

Add these 3 values through Vercel Project Settings → Environment Variables, selecting **Preview**, not Production:

```dotenv
SERPAPI_API_KEY=<your-private-serpapi-key>
WAYFARER_AI_BETA_TOKEN=<64-character-unique-random-private-code>
WAYFARER_TRAVEL_ENABLED=true
```

These values were previously set on **a different Vercel project**; they are *not automatically shared* with `wayfarer-journey-ai`. Do not paste secrets into ChatGPT or GitHub. Keep existing `GROQ_API_KEY` server-side and unchanged.

- No real provider call occurs if `WAYFARER_TRAVEL_ENABLED` is absent/false or the SerpApi key is missing.
- User must explicitly enter **beta code**, which is distinct from `SERPAPI_API_KEY`, in the browser.
- A successful user request may use up to **two** SerpApi search credits (Google Flights and Hotels). Free quota is finite and provider pricing/terms may change.
- A user can search from 1–9 adults for flights; hotel occupancy is restricted to one shared room for 1–2 adults. Check-in/check-out must be distinct and within 31 days. This is a beta validation limit, not worldwide production coverage.
- The original Groq AI flow **does not yet ingest these provider search results** or dynamically optimize booked itineraries. It continues to compose from public-source context. Do not claim autonomous priced booking agents.

## Known limitations

- Flight search is *not* verified seat availability or ticket sale; booking choice/return-leg confirmation need additional verified provider steps.
- Hotel search returns published *search prices*, not confirmed occupancy or actual bookability.
- Universal restaurant menu prices, transit fares, visas, and real-time disruptions are not provided.
- SerpApi API allowance can be consumed rapidly if made public; add a durable quota/auth layer before general release.
- The premium project source is not yet in the connected GitHub repository; exporting this package does not connect Vercel to GitHub automatically.
